# AetherAccess

Landing page initiale pour **AetherAccess Rénovation**, un assistant IA destiné aux professionnels francophones de la rénovation et de l’aménagement intérieur.

## Démarrer localement

```bash
npm install
npm run dev
```

## Construire

```bash
npm run build
```

Cette première version est une landing page statique : aucun compte utilisateur, paiement, appel IA ou stockage de données n’est activé.
